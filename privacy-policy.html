Privacy Policy

N Meeting Room Reservation (Chrome Extension) · Effective Date: March 1, 2026 · Revised: October 22, 2026

1. Purpose of Collection and Use of Personal Information

This extension is a helper tool for the Naver internal meeting room reservation service (reserve.navercorp.com). It does not collect personally identifiable information such as names, emails, employee numbers, or schedule contents. It collects only anonymous usage statistics to improve its features (see Section 2).

2. Personal Information Collected

This extension does not directly collect any personal information. It uses authentication cookies from Naver internal services that the user has already logged into to make API calls. During this process, cookie information is processed only within the browser.

To improve its features, the extension collects the following anonymous usage statistics:

  • Usage event types (room search, reservation, recurring reservation, etc.) and aggregate values such as counts and service type
  • Extension version
  • A random anonymous identifier (clientId) generated on install, not linked to any personal information

Statistics are sent to Naver's internal log collection platform (NELO, nelo2-col.navercorp.com). The collection server may record the connecting IP address. Authentication cookies are not sent.

3. Retention and Use Period of Personal Information

This extension does not operate any separate servers. Reservation and filter settings are stored only in the browser's local storage. Anonymous usage statistics are retained and deleted according to NELO's retention policy.

4. Disclosure of Personal Information to Third Parties

This extension does not provide any user personal information to third parties.

5. Destruction of Personal Information

When the extension is removed, all related local data is automatically deleted.

6. Permissions Used

  • host_permissions: reserve.navercorp.com, connect.navercorp.com — API calls are made to these domains to retrieve meeting room reservation information and verify user authentication.
  • host_permissions: calendar.navercorp.com — Applies the reserved room to the location of calendar events.
  • host_permissions: nelo2-col.navercorp.com — Sends anonymous usage statistics.

7. Data Transmission

This extension does not transmit any data to external servers other than the Naver internal domains specified above. Usage statistics are sent only to the internal NELO platform. No external analytics, advertising, or tracking tools are used.

8. Contact

For inquiries regarding this privacy policy, please contact us through the following:
